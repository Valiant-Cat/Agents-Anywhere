# 桌面内置字体

字体来自 `google/fonts`，固定提交 `5026800714d07231937d92eb4cceabf06e05d74e`。
构建直接读取本地文件，不请求 Google Fonts CSS 或字体下载服务。

| 本地文件 | 上游路径 |
| --- | --- |
| geist.ttf | ofl/geist/Geist[wght].ttf |
| geist-mono.ttf | ofl/geistmono/GeistMono[wght].ttf |
| instrument-serif.ttf | ofl/instrumentserif/InstrumentSerif-Regular.ttf |
| instrument-serif-italic.ttf | ofl/instrumentserif/InstrumentSerif-Italic.ttf |

各字体的 SIL Open Font License 见同目录对应的 `*-OFL.txt`。
