# 2.2.0.3 自部署发布说明

## 发布范围

- Web 提供 `/downloads/` 下载页面，连接手机时进入当前服务的页面。
- macOS、Windows 和 Android 下载入口跳转至自己仓库的最新正式 Release。
- iPhone / iPad 使用自己的 TestFlight 邀请；尚未配置公开邀请时显示暂未开放。
- 手机窄屏发送消息时保留消息气泡加载状态，不再重复显示等待接收任务。
- Android 正式构建使用自部署登录和更新地址，并使用长期保管的独立发行密钥；不能覆盖不同签名的上游安装包。

## 统一发布

- 正式标签为 `v2.2.0.3`，Server、Connector 和更新比较版本为 `2.2.0.3`。
- Desktop、Web 和 iOS 系统版本为 `2.2.10003`；Android 显示版本为 `2.2.0.3`，安装编号为 `202000003`。
- 从同一远程提交构建 macOS 通用 DMG、Windows x64 EXE、Android APK，并上传 iOS 到 TestFlight。
- 所有客户端任务成功后发布 GitHub Release，再部署 Web 与后端；macOS 优先于 Windows 构建。
- iOS 上传不代表 Apple 处理完成、外部审核通过或公开邀请开放；流水线不会自动提交外部审核。
- 未配置 macOS / Windows 正式签名与公证的构建仍可能被系统拦截。
- 无接口变更或数据库迁移；DSH 远程插件的独立工作区改动不包含在本版。

## 验证边界

发布前检查结果和实际产物、上传、部署结果以发布记录及 Actions 为准。无界面检查不能代替四端真实安装、登录回调和端到端会话验证。
