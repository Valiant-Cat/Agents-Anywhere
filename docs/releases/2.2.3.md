# 2.2.3 自部署发布说明

发布日期：2026-11-23。本次发布 Desktop、Web 和 Server 补丁，不修改跨端契约，不新增数据库迁移；其他客户端仍可使用 2.2.x。

## 桌面更新

macOS 下载 DMG 后校验应用标识、版本及已有签名完整性，经用户确认后退出旧版及本机 Connector，
由独立安装进程替换原安装位置并请求启动新版。不会删除用户数据。
旧版保留在安装目录旁的 `.aa-update-*/previous.app`；替换或启动命令失败时尝试恢复。
启动命令成功不代表新版已健康运行，备份不会自动删除。

安装目录必须对当前用户可写，不支持直接从 DMG 或 App Translocation 目录更新，不会自动提权。
签名身份变化可能触发系统安全确认及重新授权，不承诺跨签名身份无感升级。
本次未配置 Developer ID 签名或 Apple 公证。

现有 2.2.2 客户端首次升级仍需打开 DMG、彻底退出旧版并手动替换；
自动替换流程需安装本版后才生效。

## 连接引导

Web 与 Desktop 的「使用桌面程序连接」弹窗移除重复的「完成」按钮；
下载入口改为二开仓库最新 Release，macOS 安装说明改为通用 DMG。

## 发布顺序与验证

推送 `v2.2.3` 后，工作流先构建 macOS 通用 DMG 和 Windows x64 EXE，发布 Release 后再部署 Web/Server。
下载入口继续使用 `/download/mac/latest` 和 `/download/windows/latest` 跳转 GitHub Release。

本地已通过更新相关 24 项测试（含临时真实 DMG 挂载预复制）与 Desktop 类型检查。
全量主进程测试曾停在 Connector 测试，Web 类型检查受本地依赖未安装阻塞。
尚未进行生产安装包的真实覆盖更新或 Windows 安装验证；以 CI 运行结果及后续实机验证为准。
