# 2.3.0 自部署发布说明

本次基于 `self-hosted` 最新代码发布，包含统一身份令牌交换、DSH 远程工作区插件，以及 2.2.5 中尚未正式发布的侧边栏筛选图标和已读按钮布局调整。

## 接口与兼容

- Server 新增统一身份令牌交换接口及认证能力标记，详见[接口说明](../api/oauth-exchange.md)。
- DSH 远程插件使用统一身份登录时需要 Server 2.3.0；实例需配置对应 OIDC 提供方。官方 Cloud 是否支持该接口以其实际部署为准。
- 旧客户端可忽略新增能力字段；使用新接口的客户端必须连接支持此接口的 Server。
- 各端产品版本同步为 2.3.0；本次自动发布只构建 macOS 通用 DMG、Windows x64 EXE 并部署 Web/Server，不代表已发布 Android、iOS 或 npm 安装包。
- 统一身份接口复用现有表，不新增数据库迁移。既有迁移由标准部署流程执行。

## DSH 插件

新增远程设备、会话和时间线入口，支持明确接管后发送消息、中断及手动响应交互；任务仍在远程设备执行。插件源码随仓库发布，单独安装方式和限制见[插件说明](../../dsh-remote-next/README.md)。

## 发布与验证

发布流水线先验证并构建两个桌面平台，安装包齐备后发布正式 GitHub Release，随后部署 Web/Server；以 CI 实际结果为准。

签名与升级限制沿用 [2.2.4 说明](2.2.4.md)。此前报告的桌面启动时提前创建窗口问题尚未修复，不应将本版视作该问题的修复版本。
