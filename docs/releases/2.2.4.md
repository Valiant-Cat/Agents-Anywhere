# 2.2.4 自部署发布说明

本版包含 2.2.3 的桌面替换更新及自部署下载引导修复。2.2.3 因 macOS 界面构建失败，未生成正式 Release，也未部署服务器。

桌面生产构建改用 Webpack，避免 macOS CI 中 Turbopack 解析 Google 字体资源失败。保留现有字体与开发模式设置，不修改跨端契约、不新增数据库迁移。

推送 `v2.2.4` 后重新构建 macOS 通用 DMG 和 Windows x64 EXE；两个平台均成功后发布 Release，再自动部署 Web/Server。

本次仍未配置 Developer ID 签名和 Apple 公证。2.2.2 首次升级仍需手动退出并替换安装；自动替换功能在安装新版后生效，其他限制见 [2.2.3 说明](2.2.3.md)。

本地已通过桌面界面完整 Webpack 生产编译、TypeScript 检查、静态页面导出和通用包架构检查；安装包构建及部署以新版本 CI 结果为准。
