# 2.2.2 自部署发布说明

发布日期：2026-11-19。本次仅发布 Server 补丁，不修改跨端 API 契约、不新增数据库迁移，不要求重新构建 Desktop。

## 下载方式

`/download/mac/latest`、`/download/windows/latest` 改为返回 302，跳转到配置仓库的 GitHub 最新正式 Release 安装包，不再读取本地下载目录或代理文件流量。

使用 `AGENT_SERVER_DOWNLOAD_RELEASE_REPO=owner/repo` 替代 `AGENT_SERVER_DOWNLOAD_DIR`；自动部署默认使用本仓库。未配置仓库时入口返回 404，无需下载目录挂载。原下载文件不会自动删除。

Release 必须包含固定名称的 `Agents-Anywhere-latest.dmg` 和 `Agents-Anywhere-Setup-latest.exe`。当前标签部署不自动构建安装包或创建 Release；缺少 Release 或附件时，跳转后 GitHub 返回 404。访问者需要能够访问 GitHub，私有仓库不适合作为匿名更新源。

版本检查仍读取 Server 健康接口，与 Release 附件是否存在无关。后续更新安装包无需修改下载路由，但应先发布安装包，再协调 Server 版本升级。

部署和回退流程沿用 [2.2.1](2.2.1.md)，配置及发布步骤见[桌面安装包下载](../api/desktop-downloads.md)。
