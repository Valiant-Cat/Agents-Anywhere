# 2.2.5 自部署发布说明

Web 与 Desktop 侧边栏的设备和 Agent 筛选入口改用筛选图标并增加悬停提示，「全部标为已读」按钮靠右对齐；筛选、折叠和标记已读的行为保持不变。

本版不修改跨端接口，不新增数据库迁移；与同一 2.2 系列客户端兼容。Server 版本同步为 2.2.5，用于桌面更新检查。

推送 `v2.2.5` 后，自动构建 macOS 通用 DMG 和 Windows x64 EXE；两个平台成功后发布 GitHub Release，再部署 Web 和 Server。构建、附件发布及部署结果以 CI 实际状态为准。

签名和升级限制沿用 [2.2.4 说明](2.2.4.md)。本版不包含尚未修复的启动时提前创建窗口问题。
