# 2.2.0.2 自部署发布说明

本版包含 Web 与桌面端的会话同步修复，以及侧边栏「更多」菜单调整。

## 会话同步

- 打开的会话每 15 秒补查持久消息事件和运行状态，恢复实时通知遗漏后的消息与完成状态；不以出现助手回复作为任务结束的依据。
- 消息请求报错后，服务端后续确认同一条消息时，不再保留本地发送失败副本。
- 发送确认超时或网络中断时保留待确认消息，立即补查且不自动重发；明确拒绝发送时仍显示失败。
- Codex 发送确认晚于同一轮完成通知时，不再重新显示为运行中。
- 过程消息的展开方式与 Codex 原生界面仍可能不同，本版不隐藏或删除这些记录。

## 新会话加载

- 模型、权限及能力目录在内存中缓存 30 秒，同一作用域的并发请求合并；账号、设备、运行时、渠道或配置不同不会共用缓存。
- 模型与权限目录独立显示，单项失败不会清空另一项；过期或失败请求可再次读取。
- Connector 合并 Codex 的并发初始化，首次模型读取失败后允许重新读取。
- 冷启动仍经过 Server 与 Connector 的转发，并可能启动 Codex Runtime，不保证毫秒级返回。

## 兼容与部署

- 产品版本为 `2.2.0.2`，桌面安装器版本为 `2.2.10002`，沿用现有接口，不新增数据库迁移。
- Web、Server 与 macOS 通用 DMG、Windows x64 EXE 经发布流水线发布；Android、iOS 和 DSH 插件不单独发布。
- `2.2.0.1` 桌面端可在后端升级后检查更新；原 `2.2.4` 客户端仍需手动安装新系列版本。
- 工作区中未提交的 DSH 远程插件改动不包含在本版。

## 验证

- Web 和桌面端各 48 项消息交付、目录缓存、选择偏好、命令目录与会话恢复定向测试通过。
- Connector 全量 1724 项测试及本次修改文件的 Ruff 检查通过。
- Web 与桌面端渲染层类型检查、Web 协议检查通过。
- 本地 Web 全量测试 576 项中 574 项通过，两项管理页面测试因 Node 23 加载图表依赖报错；此前桌面渲染层全量测试也有同类两项失败，未视为全量通过。
- 尚未完成真实安装及原生 Codex 会话端到端验证，未测量真实冷启动和模型加载耗时。
- 安装包与线上部署是否成功，以发布流水线最终结果为准。
