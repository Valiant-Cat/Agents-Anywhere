# 桌面字体修复验证

本次范围仅为桌面内置字体和发布工作流的桌面验证入口，不包含本地 DSH 未提交改动。

- 原 `v2.2.0.3` 标签保持不变，Android 与 iOS 已成功的产物及 TestFlight 上传不重做。
- `desktop_only=true` 仅从工作流所在的已推送提交构建 macOS 和 Windows；不发布 Release、不部署、不运行移动端、不生成可用于正式发布复用的 `release-context`。
- 桌面验证产物仍使用当前源码版本，仅供验证，不作为新版正式发行。
- 后续桌面源码修复拟使用 `v2.2.0.4`；正式发布前需要明确记录移动端保留 `v2.2.0.3` 的独立来源，不把旧产物声称为新版本。
- 本地验证包含字体文件及许可证回归、类型检查和静态构建；Windows 安装包验证由 Actions 完成。
