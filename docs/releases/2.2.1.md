# 2.2.1 自部署发布说明

发布日期：2026-11-19。

本次为 `self-hosted` 分支的 Server 补丁发布，不是上游所有客户端的联合发布；其他端仍可保持 2.2.0。本次不修改跨端 API 契约。

## 发布内容

- Server 从 `pyproject.toml` 读取版本，健康检查返回 `2.2.1`。
- 自部署下载服务直接分发服务器上的 macOS、Windows 安装包，不转发 GitHub Release；未放置安装包时返回 404。
- 推送正式版本标签后自动构建镜像、上传服务器、备份数据库、执行迁移并检查健康状态。

## 升级和回退

部署脚本升级前备份数据库并停止旧 Server，再执行镜像内的 Alembic 迁移；实际迁移取决于目标实例当前的数据库 revision。本次版本提交本身不新增迁移。

现有实例的 OAuth 兼容补丁保留在服务器上，部署前校验对应源码基线；不匹配时停止部署。健康检查失败时尝试恢复旧镜像，不自动降级数据库。

具体部署配置见 [自动部署说明](../self-hosted-deployment.md)，下载目录和安装包放置方式见 [桌面下载服务](../api/desktop-downloads.md)。

## 安装包和验证范围

本次标签仅部署 Server，不生成或发布新的 Desktop 安装包。旧 Desktop 可能因 Server 版本升高而提示更新；下载可用前需要另行构建并上传安装包。

无数据库的下载路由与架构边界测试可以独立执行；完整 Server 测试需要一次性 PostgreSQL 测试库。健康检查不代表真人 OAuth 登录、远程 Runtime 会话或桌面更新安装流程已经验证。
